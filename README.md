# Nirav Khimat Vihar --- Project Specification

This documentation pack is the implementation blueprint for the Nirav
Khimat Vihar Dharamshala website and online booking platform.

## Documents

-   `PRD.md` --- product requirements and functional scope
-   `DESIGN.md` --- visual/UI/UX specification
-   `SECURITY.md` --- security requirements and production gate
-   `DATABASE.md` --- PostgreSQL/Supabase schema and data rules
-   `API.md` --- API contracts and booking/payment flows
-   `PROJECT_STRUCTURE.md` --- recommended Next.js project architecture
-   `ENVIRONMENT.md` --- environment variables and secret handling
-   `DEPLOYMENT.md` --- Vercel/Supabase deployment plan
-   `TESTING.md` --- QA and acceptance test plan
-   `CONTENT.md` --- website content and verification rules
-   `BOOKING_LOGIC.md` --- availability, holds, pricing and
    double-booking logic
-   `ADMIN_GUIDE.md` --- admin workflows
-   `CHANGELOG.md` --- project specification change history

## Source of truth

Business facts such as room inventory, pricing, contact details,
policies, meal timings, eligibility rules and operating hours must be
verified by Nirav Khimat Vihar management before production launch.
