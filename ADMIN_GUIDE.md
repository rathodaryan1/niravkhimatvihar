# Nirav Khimat Vihar --- Admin Operations Guide

## Daily workflow

### Morning

1.  Open Dashboard.
2.  Check today's arrivals.
3.  Check today's departures.
4.  Review pending payments.
5.  Review room availability.
6.  Resolve failed/pending bookings.

### Check-in

1.  Search booking.
2.  Verify guest details/required ID.
3.  Confirm payment/status.
4.  Mark `CHECKED_IN`.

### Check-out

1.  Open booking.
2.  Verify outstanding amount if any.
3.  Mark `CHECKED_OUT`.
4.  Release room for future inventory.

## Blocking a room

Use Calendar → select room → Block.

Reason examples: - Maintenance - Repair - Management use - Cleaning -
Renovation

Always provide start and end dates.

## Changing prices

Pricing → Room Type → Edit Price.

Future bookings retain their stored booking price unless an explicit
authorized adjustment is made.

## Cancelling a booking

1.  Open booking.
2.  Review policy.
3.  Confirm cancellation.
4.  Process refund if applicable.
5.  Verify inventory release.
6.  Confirm notification was sent.

## Security

Never share admin credentials.

Use separate accounts for staff.

Do not manually change payment records unless the payment evidence has
been verified.
